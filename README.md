# Jeen AI Solution Assignment

This repository contains both parts of the home assignment.

- [Part 1: Document Indexing and Retrieval](part1/README.md) extracts text from
  PDF and DOCX files, creates Gemini embeddings, and searches them in PostgreSQL.
- [Part 2: Multi-Agent Customer Support](part2/README.md) uses Langflow agents,
  a support database, and Gmail to handle customer support requests.

Each folder contains its own setup and run instructions.

For Part 2, use the [Langflow export](part2/support-flow.json) and the
[demo walkthrough](part2/DEMO.md) alongside the separately submitted video.
